# Module Documentation Index

Use this folder as the module-level reference library before changing a feature.

- `00-App-Shell-And-Routing.md`: startup, top-level app flow, route guards, dashboard shell.
- `01-Store-And-State.md`: global reactive store, listeners, state shape, module wrappers.
- `02-Authentication-And-Users.md`: login, Firebase Auth, user creation, staff management, profile updates.
- `03-Company-Management.md`: companies, active company selection, branding, preferences.
- `04-Contacts.md`: clients and suppliers used by sales documents.
- `05-Products-And-Inventory.md`: product catalog, variants, SKU, stock, POS product data.
- `06-POS.md`: cart, checkout, held orders, payment, completed POS transactions.
- `07-Sales-And-Documents.md`: quotes, invoices, receipts, project grouping, PDF download flow.
- `08-Expenses.md`: expense entry, receipt uploads, expense persistence caveats.
- `09-Analytics-And-Overview.md`: dashboard totals, business intelligence, chart calculations.
- `10-Templates-And-PDF.md`: document templates, template studio, print/PDF CSS contract.
- `11-Settings-And-Profile.md`: app theme preferences and current-user profile.
- `12-Shared-Composables-And-UI.md`: shared storage, PDF, SKU, confirmation button, global UI helpers.
- `13-Activity-Audit.md`: activity log display and current audit limitations.

Before editing any module, also read the matching high-level rule in `.knowledge/UIUX.md`, `.knowledge/Backend.md`, or `.knowledge/Architecture.md`.
